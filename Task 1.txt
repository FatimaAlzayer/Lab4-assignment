33 ?- edge(a,b) = edge(C,b).
C = a.

Explanation : They have predicate, , same number of arguments, and the same atom b in second argument, Therefore The variable C unifies with the atom a.

34 ?- edge(a,d) = edge(C,B).
C = a,
B = d.

Explanation : They have predicate, and same number of arguments, so atoms in each corresponding argument position unify.

35 ?- edge(C,B) = edge(a,d).

Explanation : They have predicate, and same number of arguments,  so atoms in each corresponding argument position unify.

36 ?- edge(A,f(g,h)) = edge(a,B).
A = a,
B = f(g, h).

Explanation : They have predicate, and same number of arguments, so each argument unifies in turn, variable A unifies with atom a, and Variable B unifies with the compound function f(g, h).


37 ?- edge(A,A) = edge(b,c).
false.

Explanation : The variable A appears in both positions, so it must have the same atom in both positions. But b and c are different, so they the unification fails.


38 ?- edge(A,A) = edge(b,b).
A = b.

Explanation : Since the atoms are the same, Variable A is unified with b 

39 ?- A = B, B = f.
A = B, B = f.

Explanation : A unifies with B, and B unifies with f, and because A and B are linked, eventually both variables are linked to f.

40 ?- A = B, B = f, A = e.
false.

Explanation : A is linked to B, and B is linked to f, which then makes A = f, so A = e fails because A is already linked with f.
